What this is

Paste a requirements.txt, pick the Python version and platform you deploy on, and get back the newest set of versions that install together there. If no such set exists, you get an explanation of why.

Typical uses:

  • Upgrading pins. See which packages can move forward, and which are capped by another package.
  • Before bumping Python. Check whether today's pins install on 3.14 before changing the base image.
  • Supporting older Pythons. Find the last releases that still support 3.10.

How it resolves

The resolver uses resolvelib, the backtracking resolver inside pip, and packaging for versions, specifiers, markers and wheel tags. Release data comes from PyPI's JSON Simple API (PEP 691). Dependencies are read from each wheel's published metadata (PEP 658) without downloading the wheel. Known vulnerabilities come from PyPI's advisory feed.

Like pip, it doesn't build source distributions. A release that ships only an sdist without dependency metadata is resolved without its dependencies, and the result says so.
