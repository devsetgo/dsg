How it works

The file is resolved the way pip resolves it: the same backtracking engine (resolvelib), the same PEP 440 version rules, and the same metadata from PyPI. The difference is that it answers for the Python version and platform you pick, not the one it runs on.

  • Requires-Python rules out releases that the target can't install.
  • Environment markers such as ; python_version < "3.11" are evaluated for the target.
  • Only wheels built for the target platform count, with the source distribution as a fallback.
  • Extras like fastapi[all] pull in their own dependencies.
  • Yanked releases are skipped unless you pin one exactly.

When a package can't reach its newest release, the result says which package's requirement is holding it back.
